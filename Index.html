Migratioon P is a personal utility designed to help migrate Pinterest boards and Pins between Pinterest accounts owned and managed by the same person. The application uses the Pinterest API to access and manage Pinterest content only after the account owner explicitly authorizes the application through Pinterest's OAuth authorization flow. Purpose The purpose of this application is to facilitate the migration and organization of the user's own Pinterest boards and Pins between their own Pinterest accounts. The application is not intended to access, collect, sell, or distribute other users' Pinterest content. Data usage The application may access Pinterest boards and Pins that the authorized user permits it to access through the Pinterest API. The application does not sell personal information or Pinterest content to third parties. Contact For questions about this application or its privacy practices, please contact the application owner through the contact information associated with the Pinterest Business account used to administer the application.
